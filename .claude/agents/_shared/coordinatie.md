# Agent Coördinatie

Overzicht van alle agents, hun rol en huidige focus.
Elke agent leest dit bij opstart. Elke agent werkt hier zijn status bij.

## Actieve Agents

| Agent | Rol | Huidige taak | Status |
|-------|-----|--------------|--------|
| schrijver | Inhoud schrijven | — | beschikbaar |
| onderzoeker | Bronnen en concepten verdiepen | — | beschikbaar |
| redacteur | Teksten redigeren en structureren | — | beschikbaar |

## Spelregels

1. **Één taak tegelijk per agent** — schrijf je huidige taak in de tabel
2. **Geen overlap** — check de tabel vóór je begint
3. **Taken via taken.md** — nooit een eigen lijst
4. **Berichten via communicatie.md** — nooit losse bestanden
5. **Status altijd bijwerken** — ook als je klaar bent
